# LL(1) 分析完整笔记

## 一、LL(1) 是什么

| 字母 | 含义 |
|------|------|
| 第一个 L | **从左到右扫描**输入（Left-to-right） |
| 第二个 L | 产生**最左推导**（Leftmost derivation） |
| 1 | **1 个前瞻符号**决定用哪条产生式 |

**核心思想**：自顶向下预测分析，不回溯。根据当前栈顶非终结符和下一个输入符号，从预测分析表中唯一确定要用的产生式。

---

## 二、前置知识：FIRST 集和 FOLLOW 集

### 2.1 FIRST 集

FIRST(α) = 从 α 出发能推导出的所有**终结符开头**的集合，如果 α ⇒* ε，则 ε ∈ FIRST(α)。

**求法规则**：

| 情况 | 规则 |
|------|------|
| X → a... | a ∈ FIRST(X) |
| X → ε | ε ∈ FIRST(X) |
| X → Y... | FIRST(Y) \ {ε} ⊆ FIRST(X)；若 Y ⇒* ε，继续看下一个符号 |

### 2.2 FOLLOW 集

FOLLOW(A) = 在某些句型中**紧跟在 A 后面**的终结符集合（$ 表示输入结束）。

**求法三条规则**（注意：以下用 **模板符号** 描述，不要与文法具体符号混淆）：

把产生式看作模板：**A → α B β**
- **A** = 产生式左部
- **B** = 正在求 FOLLOW 的目标非终结符
- **α** = B 前面的部分（可为空）
- **β** = B 后面的部分（可为空）

| 规则 | 条件 | 操作 |
|------|------|------|
| **规则 0** | S 是开始符号 | $ ∈ FOLLOW(S) |
| **规则 1** | A → α **B** β 且 β 不是 ε | FIRST(β) \ {ε} ⊆ FOLLOW(B) |
| **规则 2** | A → α **B**（B 在末尾）或 A → α **B** β 且 β ⇒* ε | FOLLOW(A) ⊆ FOLLOW(B) |

---

## 三、LL(1) 分析表构造

预测分析表 M 的行 = **非终结符**，列 = **终结符 + $**。

### 两条填表规则

对每条产生式 **A → α**：

| 规则 | 条件 | 动作 |
|------|------|------|
| **规则 A** | 对每个 a ∈ FIRST(α) 且 a ≠ ε | M[A, a] = A → α |
| **规则 B** | 若 ε ∈ FIRST(α)（α ⇒* ε） | 对每个 b ∈ FOLLOW(A)：M[A, b] = A → α（含 $） |

---

## 四、完整实例演示

### 文法

```
G[E]:
(1) E  → T E'
(2) E' → + T E'
(3) E' → ε
(4) T  → F T'
(5) T' → * F T'
(6) T' → ε
(7) F  → ( E )
(8) F  → id
```

### 4.1 FIRST 集

```
FIRST(F) = { (, id }
FIRST(T') = { *, ε }
FIRST(T) = { (, id }       ∵ T → F T'，FIRST(F) = {(,id}，FIRST(F)不含ε → 不进T'
FIRST(E') = { +, ε }
FIRST(E) = { (, id }       ∵ E → T E'，FIRST(T) = {(,id}
```

**求 FIRST 口诀**：终结符直接加，ε 直接加，非终结符查完传。

### 4.2 FOLLOW 集

```
FOLLOW(E) = { $, ) }       ∵ 规则0 + F→(E) → ) 进FOLLOW(E)
FOLLOW(E') = { $, ) }      ∵ E→TE' → FOLLOW(E)进FOLLOW(E')（E'是末尾）
FOLLOW(T) = { +, $, ) }    ∵ E→TE' → FIRST(E')\{ε}={+} + ε∈FIRST(E')→FOLLOW(E)={$,)}
FOLLOW(T') = { +, $, ) }   ∵ T→FT' → FOLLOW(T)进FOLLOW(T')
FOLLOW(F) = { *, +, $, ) } ∵ T→FT' → FIRST(T')\{ε}={*} + ε∈FIRST(T')→FOLLOW(T)={+,$,)}
```

### 4.3 填表过程（逐条填 12 项）

#### 产生式 (1) E → T E'

- FIRST(T E')：
  - FIRST(T) = {(, id}，不含 ε
  - FIRST(T E') = {(, id}
  - **规则 A**：M[E, (] = E→T E'，M[E, id] = E→T E'
  - 规则 B 不触发（FIRST(T E') 不含 ε）

#### 产生式 (2) E' → + T E'

- FIRST(+ T E') = {+}
  - **规则 A**：M[E', +] = E'→+ T E'
  - 规则 B 不触发

#### 产生式 (3) E' → ε

- FIRST(ε) = {ε}
  - 规则 A 无触发
  - **规则 B**：FOLLOW(E') = {$, )} → M[E', $] = E'→ε，M[E', )] = E'→ε

#### 产生式 (4) T → F T'

- FIRST(F T')：
  - FIRST(F) = {(, id}，不含 ε
  - FIRST(F T') = {(, id}
  - **规则 A**：M[T, (] = T→F T'，M[T, id] = T→F T'
  - 规则 B 不触发

#### 产生式 (5) T' → * F T'

- FIRST(* F T') = {*}
  - **规则 A**：M[T', *] = T'→* F T'
  - 规则 B 不触发

#### 产生式 (6) T' → ε

- FIRST(ε) = {ε}
  - 规则 A 无触发
  - **规则 B**：FOLLOW(T') = {+, $, )} → M[T', +] = T'→ε，M[T', $] = T'→ε，M[T', )] = T'→ε

#### 产生式 (7) F → ( E )

- FIRST(( E )) = {(} — 注意 ( 是终结符
  - **规则 A**：M[F, (] = F→( E )
  - 规则 B 不触发

#### 产生式 (8) F → id

- FIRST(id) = {id}
  - **规则 A**：M[F, id] = F→id
  - 规则 B 不触发

### 4.4 最终 LL(1) 分析表

| 非终结符 | id | + | * | ( | ) | $ |
|---------|:---:|:---:|:---:|:---:|:---:|:---:|
| **E** | E→TE' | | | E→TE' | | |
| **E'** | | E'→+TE' | | | E'→ε | E'→ε |
| **T** | T→FT' | | | T→FT' | | |
| **T'** | | T'→ε | T'→*FT' | | T'→ε | T'→ε |
| **F** | F→id | | | F→(E) | | |

### 4.5 检查：是否 LL(1) 文法？

**条件 1（FIRST 无交集）**：每个非终结符的任意两条产生式的 FIRST 集不相交。
- E → T E'：只有一条产生式，OK
- E' → + T E' | ε：FIRST(+TE')={+}，FIRST(ε)={ε}，不相交，OK
- T → F T'：只有一条，OK
- T' → * F T' | ε：FIRST(*FT')={*}，FIRST(ε)={ε}，不相交，OK
- F → (E) | id：FIRST(()={(}，FIRST(id)={id}，不相交，OK

**条件 2（FIRST-FOLLOW 无交集）**：对每个 ε-产生式，FIRST(A) 与 FOLLOW(A) 不相交。
- E'：FIRST(E')={+,ε}，FOLLOW(E')={$,)}。+ 不在 {$,)} 中，OK
- T'：FIRST(T')={*,ε}，FOLLOW(T')={+,$,)}。* 不在 {+,$,)} 中，OK

✅ 该文法是 LL(1) 文法。

## 五、栈驱动分析过程

以输入 `id + id * id` 为例：

| 步骤 | 栈（栈顶在右） | 输入 | 动作 |
|:----:|:--------------|:------|:-----|
| 0 | $ E | id + id * id $ | 初始状态 |
| 1 | $ E' T | id + id * id $ | M[E, id] = E→T E' |
| 2 | $ E' T' F | id + id * id $ | M[T, id] = T→F T' |
| 3 | $ E' T' id | id + id * id $ | M[F, id] = F→id |
| 4 | $ E' T' | + id * id $ | 匹配 id，弹出 |
| 5 | $ E' | + id * id $ | M[T', +] = T'→ε |
| 6 | $ E' T + | + id * id $ | M[E', +] = E'→+ T E' |
| 7 | $ E' T | id * id $ | 匹配 +，弹出 |
| 8 | $ E' T' F | id * id $ | M[T, id] = T→F T' |
| 9 | $ E' T' id | id * id $ | M[F, id] = F→id |
| 10 | $ E' T' | * id $ | 匹配 id，弹出 |
| 11 | $ E' T' F * | * id $ | M[T', *] = T'→* F T' |
| 12 | $ E' T' F | id $ | 匹配 *，弹出 |
| 13 | $ E' T' id | id $ | M[F, id] = F→id |
| 14 | $ E' T' | $ | 匹配 id，弹出 |
| 15 | $ E' | $ | M[T', $] = T'→ε |
| 16 | $ | $ | M[E', $] = E'→ε |
| 17 | ✅ 接受 | | 栈空 + 输入空 |

**关键规则**：
- 栈顶是**终结符** → 匹配输入，同时弹出
- 栈顶是**非终结符** → 查表 M[非终结符, 当前输入]，用产生式右侧替换（逆序入栈）
- 查表为**空白** → 报错（不是合法句子）
- 栈顶非终结符匹配 **ε-产生式** → 直接弹出（不消耗输入）

## 六、LL(1) 文法判别条件

一个文法是 LL(1) 的，当且仅当：

### 条件 1：FIRST 不相交
对任意 A → α | β（两个不同产生式）：
```
FIRST(α) ∩ FIRST(β) = ∅
```

### 条件 2：FIRST-FOLLOW 不相交
若 A ⇒* ε（存在 ε-产生式）：
```
FIRST(A) ∩ FOLLOW(A) = ∅
```
（注意：对 ε-产生式，FIRST(α) = {ε}，规则 B 会填到 FOLLOW(A) 中；如果 FOLLOW(A) 和 FIRST(A) 有交集 → 冲突）

## 七、要点总结

| 事项 | 要点 |
|------|------|
| 分析表本质 | 用前瞻符号预测应该用哪条产生式 |
| 规则 A | 正常情况：FIRST(α) 里的终结符告诉你要用 A→α |
| 规则 B | ε-产生式：看看 FOLLOW(A) 什么时候允许你消掉 A |
| 表格空白 | 报错（非 LL(1) 文法或非法句子） |
| 栈驱动 | 匹配 + 预测，16 步完成 id+id*id |
| LL(1) 条件 | FIRST 不相交 + FIRST-FOLLOW 不相交 |

| 方法 | 方向 | 推导 | 状态数 | 能力 |
|:----:|:----:|:----:|:------:|:----:|
