# 代码解释

## 一、TINY词法规则：

- 关键字：`if`, `then`, `else`, `end`, `repeat`, `until`, `read`, `write`
- 标识符：`ID = letter letter*`（字母开头，后续为字母）
- 数字：`NUM = digit digit*`
- 空白符：空格、换行`\n`、制表符`\t`（跳过）
- 注释：`{...}` 花括号包围，不可嵌套
- 专用符号：`+`, `-`, `*`, `/`, `<`, `=`, `(`, `)`, `:=`

---

## 二、DFA状态机设计

```
stateDiagram-v2
    [*] --> START

    START --> INNUM : digit
    START --> INID : letter
    START --> INASSIGN : :
    START --> INCOMMENT : {
    START --> START : whitespace
    START --> DONE : 其他符号

    INNUM --> INNUM : digit
    INNUM --> DONE : other (回退)

    INID --> INID : letter
    INID --> DONE : other (回退)

    INASSIGN --> DONE : =
    INASSIGN --> DONE : other (错误)

    INCOMMENT --> INCOMMENT : other
    INCOMMENT --> START : }

    DONE --> [*]
```

**5个DFA状态：**

| 状态 | 含义 | 转移条件 |
|------|------|----------|
| `START` | 起始状态 | 根据首字符分发 |
| `INNUM` | 读取数字 | digit→继续，其他→完成NUM |
| `INID` | 读取标识符 | letter→继续，其他→完成ID |
| `INASSIGN` | 读取赋值号 | `=`→完成ASSIGN，其他→错误 |
| `INCOMMENT` | 在注释中 | `}`→返回START，其他→继续 |
| `DONE` | 完成识别 | 返回Token |

## 三、代码结构

### 3.1 Token类型枚举（第15-35行）

```c
typedef enum {
    /* 保留字 */
    IF, THEN, ELSE, END, REPEAT, UNTIL, READ, WRITE,
    /* 标识符和数字 */
    ID, NUM,
    /* 专用符号 */
    PLUS, MINUS, TIMES, OVER, LT, EQ, LPAREN, RPAREN, ASSIGN, SEMI,
    /* 特殊标记 */
    ENDFILE, ERROR
} TokenType;
```

### 3.2 DFA状态枚举（第38-45行）

```c
typedef enum {
    START,      // 起始
    INNUM,      // 读数字
    INID,       // 读标识符
    INASSIGN,   // 读:=
    INCOMMENT,  // 读注释
    DONE        // 完成
} StateType;
```

### 3.3 保留字查找表（第75-98行）

```c
static ReservedWord reservedWords[] = {
    {"if", IF}, {"then", THEN}, {"else", ELSE}, {"end", END},
    {"repeat", REPEAT}, {"until", UNTIL}, {"read", READ}, {"write", WRITE}
};

// 查找函数：匹配返回关键字类型，否则返回ID
static TokenType reservedLookup(char* s) {
    for (int i = 0; i < RESERVED_WORDS_COUNT; i++) {
        if (strcmp(s, reservedWords[i].str) == 0)
            return reservedWords[i].tok;
    }
    return ID;
}
```

### 3.4 核心函数 getToken()（第165-320行）

**主循环逻辑：**

```c
TokenType getToken(void) {
    StateType state = START;
    while (state != DONE) {
        int c = getNextChar();
        switch (state) {
            case START:
                if (isdigit(c)) state = INNUM;
                else if (isalpha(c)) state = INID;
                else if (c == ':') state = INASSIGN;
                else if (c == '{') state = INCOMMENT;
                else if (isspace(c)) /* 跳过 */;
                else /* 单字符符号或错误 */;
                break;
            case INNUM:
                if (!isdigit(c)) { ungetNextChar(); state = DONE; currentToken = NUM; }
                break;
            case INID:
                if (!isalpha(c)) { ungetNextChar(); state = DONE; currentToken = ID; }
                break;
            case INASSIGN:
                if (c == '=') currentToken = ASSIGN;
                else currentToken = ERROR;
                state = DONE;
                break;
            case INCOMMENT:
                if (c == '}') state = START;  // 注释结束，回到起点
                break;
        }
    }
    // 标识符完成后检查是否为保留字
    if (currentToken == ID)
        currentToken = reservedLookup(tokenString);
    return currentToken;
}
```

**关键点：**
1. `ungetNextChar()` 回退字符 - 当发现非数字/字母时，该字符属于下一个Token
2. 注释处理 - `INCOMMENT`状态下遇到`}`才返回`START`，内容全部丢弃
3. 保留字识别 - 先按ID读取，完成后查表判断是否为关键字

## 四、运行

### 编译
```bash
gcc -o tiny_lexer tiny_lexer.c
```

### 测试程序 sample.tny

```
{ 注释会被跳过 }
read x;
if x < 0 then
    x := 0 - x
end;
write x
```

### 运行
```bash
./tiny_lexer sample.tny
```

### 输出示例
```
   4: read x;
        4: READ      
        4: ID        , val= x
        4: SEMI      
   5: if x < 0 then
        5: IF        
        5: ID        , val= x
        5: LT        
        5: NUM       , val= 0
        5: THEN      
```
