# 嵌入式测试实验步骤指南

## 实验概述
这是一个嵌入式测试实验，使用ETest工具对飞镖游戏系统进行黑盒测试。系统包含两个主要功能：
1. **发射飞镖**(shoot)：发送飞镖类型和数量
2. **接收靶区信息**(target)：接收飞镖击中的靶区位置

## 实验环境
- ETest测试工具
- 虚拟串口工具VSPD
- 待测软件Dart.exe

## 实验步骤

### 第一步：安装和配置虚拟串口工具VSPD
1. 解压"虚拟串口工具.rar"文件
2. 打开解压后的文件夹，运行"vspdconfig.exe"
3. 创建新的串口对（建议创建COM1-COM2和COM5-COM6两对）
4. 创建完成后需要重启电脑使虚拟串口生效

### 第二步：安装ETest测试工具
1. 解压"ETest_win64_2025.zip"文件
2. 进入解压后的文件夹，打开"dev"文件夹
3. 运行"ETest.exe"启动测试工具

### 第三步：配置ETest环境和项目
1. 在ETest中打开"project"文件夹
2. 检查环境配置(env.env文件)是否正确：
   - 仿真设备连接到COM1和COM5
   - 实物设备连接到COM2和COM6
3. 确认协议文件(shoot.prot和target.prot)已正确配置
4. 检查测试数据文件(data.yml等)是否准备就绪

### 第四步：运行待测软件
1. 进入"待测系统\被测软件"文件夹
2. 运行"Dart.exe"
3. 记住软件显示的串口号（应该是COM1和COM5）
4. 点击确定进入软件运行界面

### 第五步：设计并执行测试用例

#### 1. 飞镖发射测试
- 运行1shoot.lua文件，测试不同类型和数量的飞镖发射
- 修改测试数据，测试边界值（如0个飞镖、最大数量飞镖等）

#### 2. 靶区接收测试
- 运行2target.lua文件，测试不同靶区的接收
- 修改代码测试各个靶区（1-6区）

#### 3. 接口测试
- 运行3interface_shoot.lua和4interface_target.lua进行接口测试

#### 4. 测试数据修改
- 修改data_biao.yml中的测试数据，创建更多测试用例
- 测试特殊情况如负数、超范围值等

### 第六步：编写实验报告
1. 使用"软件测试课程实验报告模板.docx"编写报告
2. 报告需要包含：
   - 测试代码截图
   - 测试用例描述（按照示例格式）
   - 测试结果分析
   - 发现的问题和改进建议

### 第七步：打包提交作业
1. 创建以"学号-姓名"命名的压缩包
2. 包含以下内容：
   - ETest项目文件（整个project文件夹）
   - 实验报告文档
3. 在截止日期前发送到指定邮箱：https://send2me.cn/JFNHS87R/SaOauIF1-conCw

## 注意事项
1. 修改Lua代码后记得按Ctrl+S保存
2. 运行测试前确保虚拟串口已正确配置
3. 测试过程中注意观察待测软件的反应
4. 截图保存重要的测试结果
