**题目：**

```c
int findMax(int a, int b, int c) {
    int max = a;
    if (b > max) {
        max = b;
    }
    if (c > max) {
        max = c;
    }
    return max;
}
```

### 示例3：条件覆盖和分支覆盖

**题目：**
保险金额计算，写出测试用例，要求满足条件覆盖和分支覆盖

```java
int insuranceCost(int age, boolean isSmoker, boolean hasDisease) {
    int p = 1000;
    if (age > 60 && isSmoker) {
        p *= 2;
    } else if (age > 30 && hasDisease) {
        p *= 1.5;
    } else if (age <= 30) {
        p *= 0.8;
    }
    return p;
}
```
