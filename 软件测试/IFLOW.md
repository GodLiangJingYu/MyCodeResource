# 软件测试课程学习资料

## 目录概述

这是一个软件测试课程的学习资料目录，包含课程课件、实验材料、作业和练习题。主要用于西北工业大学软件测试课程的学习和实践。

## 课件文件

## 实验项目

### 实验1：开发者测试（exec1）

**项目类型**：Java单元测试项目

**测试对象**：Nextday程序（计算给定日期的下一天）

**技术栈**：
- Java
- JUnit 4.13.2
- hamcrest-core 1.3
- IntelliJ IDEA

**核心类**：
- `Year.java`：年份类，处理闰年判断
- `Month.java`：月份类，处理月份天数计算
- `Day.java`：日期类，处理日期验证和递增
- `Date.java`：日期组合类
- `Nextday.java`：主功能类，计算下一天
- `DemoTest.java`：JUnit测试类

**测试覆盖**：
- 语句覆盖测试
- 边界值测试（闰年、月末、年末）
- 异常情况测试（无效输入）

**运行方式**：
```bash
# 使用IntelliJ IDEA运行
1. 打开项目
2. 右键点击 DemoTest.java
3. 选择 Run 'DemoTest'
```

**关键文件**：
- `src/`：源代码目录
- `实验一指导手册.docx`：实验指导文档
- `覆盖率截图.png`：测试覆盖率截图

### 实验2：嵌入式测试（exec2）

**项目类型**：嵌入式系统黑盒测试

**测试对象**：飞镖游戏系统（Dart.exe）

**技术栈**：
- ETest测试工具
- Lua脚本
- 虚拟串口工具VSPD

**测试功能**：
1. 发射飞镖（shoot）：发送飞镖类型和数量
2. 接收靶区信息（target）：接收飞镖击中的靶区位置

**测试方法**：黑盒测试、接口测试

**核心文件**：
- `project/`：ETest项目目录
  - `func/`：Lua测试脚本
  - `prot/`：协议文件
  - `testdata/`：测试数据文件（YAML格式）
  - `run/`：运行配置文件
- `待测系统/被测软件/Dart.exe`：待测程序
- `嵌入式测试实验步骤.md`：详细实验步骤

**运行方式**：
```bash
# 1. 配置虚拟串口（使用VSPD工具）
# 2. 启动ETest工具
# 3. 运行Dart.exe
# 4. 在ETest中执行测试脚本
```

**测试脚本示例**：
- `1shoot.lua`：飞镖发射测试
- `2target.lua`：靶区接收测试
- `3interface_shoot.lua`：发射接口测试
- `4interface_target.lua`：靶区接口测试

### 实验3：Web自动化测试（exec3）

**项目类型**：Web自动化测试

**测试对象**：安居客网站（https://www.anjuke.com/）

**技术栈**：
- Python 3.8+
- Selenium WebDriver
- Chrome浏览器
- pytest

**测试场景**：
1. 打开安居客网页版，点击租房
2. 地址选择"南京"
3. 点击"地铁找房"
4. 选择地铁2号线，马群站
5. 设置租金范围（5000-8000元）
6. 选择"整租"
7. 房屋类型选择"普通住宅"
8. 搜索"经天路"
9. 选择"视频看房"
10. 测试排序功能（租金、最新）
11. 点击第一个房源查看详情

**运行方式**：
```bash
# 进入pytest目录
cd exec/pytest

# 运行单元测试
python test.py unit

# 运行实际测试
python test.py
```

**关键文件**：
- `pytest/test.py`：主测试脚本
- `chromedriver.exe`：Chrome浏览器驱动
- `安居客功能测试需求文档.pdf`：需求文档

**注意事项**：
- 需要安装Chrome浏览器
- 需要网络连接
- 测试可能因网站更新而失效

## 常见问题

**Q1：如何运行Java单元测试？**
A：使用IntelliJ IDEA打开exec1项目，右键点击DemoTest.java，选择Run 'DemoTest'。

**Q2：ETest工具无法启动怎么办？**
A：确保虚拟串口已正确配置，并且已重启电脑使虚拟串口生效。

**Q3：Web自动化测试失败怎么办？**
A：检查ChromeDriver版本是否与Chrome浏览器版本匹配，确保网络连接正常。

**Q4：测试用例设计需要多少个？**
A：实验4要求不少于20个测试用例，覆盖基本功能、性能、兼容性和安全性四个维度。
