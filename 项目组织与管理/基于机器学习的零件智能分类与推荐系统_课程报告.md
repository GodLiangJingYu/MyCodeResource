# 基于机器学习的零件智能分类与推荐系统 - 课程报告

## 1. 项目概述

本项目旨在开发一个基于机器学习的零件智能分类与推荐系统，通过对CAD模型的几何特征进行分析，实现零件的自动化分类、智能检索和精准推荐。系统采用先进的特征提取技术，直接分析CAD模型的几何形状特征，跳出传统依赖元数据的局限。通过训练有监督分类模型，能够自动识别并归类新上传的零件，实现高效、准确的分类管理；结合无监督聚类算法，进一步挖掘零件库中的潜在族群，助力企业标准化与知识发现。

### 1.1 系统用户角色

系统主要面向以下四类用户：

1. **设计工程师**：负责零件设计，需要查找相似已有零件以避免重复设计
2. **零件库管理员**：负责零件分类管理，需要系统自动分类和批量修正功能
3. **采购工程师**：负责零件采购，需要查找可替代零件以降低采购成本
4. **系统管理员**：负责系统维护，需要监控模型性能和触发模型重训练

### 1.2 核心功能

1. **智能相似件检索**：支持"以图搜图"，基于零件几何形状进行相似性检索，5秒内返回最多10个相似零件
2. **3D交互预览**：支持鼠标旋转、滚轮缩放，帧率≥30fps的3D模型预览
3. **自动分类系统**：一键启动自动分类任务，2分钟内完成100+零件分类，准确率≥90%
4. **批量修正功能**：支持批量修正错误标签，并自动加入重训练队列
5. **定时任务管理**：支持设置定时自动分类任务，非工作时间完成增量更新
6. **智能筛选功能**：支持按置信度筛选（如≤70%），优先复核可能错误标签
7. **替代件审批流程**：支持标记相似零件为"可替代"并提交审批流程
8. **模型性能监控**：实时监控分类模型的准确率、召回率和F1分数
9. **自动重训练机制**：支持设置自动重训练触发条件（如新增标注数据≥100条）

## 2. 项目预启动即商业论证或可行性分析

### 2.1 为什么做这个项目？

在现代制造业和工程设计领域，企业往往拥有庞大的零件库，包含数以万计的CAD模型。传统零件分类和检索方式高度依赖人工，工程师需要手动为每个零件添加分类编码和标签，不仅耗时耗力，还容易出现人为错误和主观偏差。现有的零件搜索通常只能通过编号或名称关键字，难以支持基于形状的智能查找，导致已有零件难以被有效复用，企业常常为相似的需求重新设计零件，加重了制造和管理负担。随着数字化转型的推进，企业亟需一种智能、自动化的解决方案，提升零件管理效率，促进设计重用，降低成本。

### 2.2 这个项目的特色在哪里？（与市场已有产品有何差异性，以什么吸引用户？）

本项目的主要特色在于：

1. **超越传统元数据的局限**：直接对CAD模型的几何特征进行分析，而不是依赖零件的名称、编号等元数据，实现真正的"以形搜形"功能。

2. **智能自动化分类**：利用机器学习算法自动对零件进行分类，大幅提升效率并减少人为错误，相比传统人工分类方式，效率提升可达80%以上。

3. **知识发现能力**：通过无监督学习方法，自动发现零件库中潜在的、未被定义的零件家族，为企业标准化工作提供数据支持。

4. **多维度可视化呈现**：提供3D零件预览与高亮显示关键特征、二维散点图展示所有零件在特征空间中的分布、相似零件检索结果列表与3D对比视图等功能。

### 2.3 智能化如何体现？

本项目的智能化主要体现在以下几个方面：

1. **智能特征提取**：采用先进的机器学习算法（如3D卷积神经网络、多视图CNN或PointNet++），自动从CAD模型中提取最具代表性的几何特征。

2. **智能分类与聚类**：通过有监督学习实现零件的自动分类，通过无监督学习发现潜在的零件族群，实现知识的自动发现。

3. **智能相似性检索**：基于特征向量间的相似度计算，实现"以图搜图"式的智能检索，为工程师推荐最相似的已有零件。

4. **智能可视化分析**：通过t-SNE/PCA等降维技术，将高维特征映射到二维空间，直观展示零件间的相似关系和分布情况。

### 2.4 项目的初步需求？

1. **功能需求**：
   - **设计工程师功能**：
     - 上传3D模型文件（.step/.stl）并查找相似件，5秒内返回最多10个相似零件
     - 3D交互式预览窗口，支持鼠标左键旋转、滚轮缩放，帧率≥30fps
     - 导出Excel清单（含零件编号、相似度、材料、库存数量），3秒内生成并自动下载
     - 对相似度评分低于70%的零件标记"不可复用"，提供反馈机制
   - **零件库管理员功能**：
     - 一键启动"自动分类"任务，2分钟内完成100+未分类零件，准确率≥90%
     - 批量修正错误标签，支持选择多个零件批量修改类别
     - 设置定时任务（如每周日凌晨2点运行自动分类），非工作时间完成增量更新
     - 按置信度筛选（如≤70%），优先复核可能错误标签的零件
   - **采购工程师功能**：
     - 在零件详情页点击"查找相似件"，按相似度排序展示零件列表
     - 查看每个相似零件的预估成本和库存状态，判断是否可替代使用
     - 标记相似零件为"可替代"并提交审批流程，推动标准化和零件复用
     - 导出相似零件对比报告（几何相似度、成本、库存）为Excel格式
   - **系统管理员功能**：
     - 查看分类模型的准确率、召回率和F1分数，按类别查看详细指标
     - 上传新标注零件数据并触发模型重训练任务，显示训练进度和预计完成时间
     - 对比新旧模型性能指标，决定是否部署新模型
     - 设置自动重训练触发条件（如新增标注数据≥100条时自动触发）

2. **性能需求**：
   - 支持常见CAD格式（STEP、STL、DWG/DXF等）
   - 相似件检索响应时间≤5秒
   - 3D预览帧率≥30fps
   - 自动分类任务处理速度≥50零件/分钟
   - Excel导出时间≤3秒
   - 系统支持至少10000个零件的数据库管理
   - 分类准确率≥90%
   - 置信度筛选响应时间≤1秒

3. **用户界面需求**：
   - 直观的3D模型预览界面，支持交互式操作
   - 友好的用户交互界面，支持批量操作
   - 实时进度显示和状态反馈
   - 响应式设计，支持不同设备访问
   - 提供API接口供系统集成
   - 支持多角色权限管理

### 2.5 如涉及数据集，后期是否可获得？

本项目所需的数据集主要包括：

1. **CAD模型数据**：可通过企业现有零件库获取，或从公开的CAD模型数据库（如GrabCAD、Thingiverse等）获取。这些数据集在项目后期是可获得的，且数量庞大，足以支持机器学习模型的训练。

2. **标注数据**：对于有监督分类任务，需要一定量的已标注数据。初期可通过人工标注小批量数据，然后通过主动学习技术逐步扩展标注数据集。企业内部通常已有部分分类标准，可作为初始标注依据。

3. **评估数据**：可通过交叉验证、保留测试集等方式从现有数据中划分，确保模型评估的可靠性。

## 4. 项目计划

### 4.1 综合管理

#### 4.1.1 制定项目管理计划——整个项目的计划，包括执行/监控/收尾的做法

**项目执行计划**：

1. **开发方法论**：
   - 采用敏捷开发方法，每2周为一个迭代周期
   - 每个迭代周期结束进行演示和回顾，重点展示用户故事实现情况
   - 持续集成和持续交付（CI/CD），确保代码质量和快速交付
   - 用户故事驱动开发，确保每个功能都有明确的验收标准

2. **团队协作**：
   - 每日站会：每天上午9:00，15分钟，汇报进度、计划和障碍
   - 周例会：每周五下午，1小时，回顾本周进展和下周计划
   - 迭代计划会议：每2周一次，2小时，规划下个迭代的用户故事
   - 迭代回顾会议：每2周一次，1小时，总结经验教训和改进措施
   - 用户故事评审会：每个迭代中期，邀请用户代表参与评审

3. **质量管理**：
   - 代码审查：所有代码必须经过同行审查，确保代码质量和规范
   - 单元测试：代码覆盖率不低于80%，关键模块覆盖率不低于90%
   - 集成测试：每个模块完成后进行集成测试，确保模块间接口正确
   - 性能测试：针对关键性能指标（如响应时间、处理速度）进行专项测试
   - 用户验收测试：基于用户故事的验收标准进行UAT，确保满足用户需求
   - 回归测试：每次迭代前进行回归测试，确保新功能不影响现有功能

4. **配置管理**：
   - 版本控制：使用Git进行代码版本管理，确保代码可追溯
   - 分支策略：采用Git Flow工作流，主分支保护，功能分支开发

   - 数据库管理：使用数据库迁移脚本管理数据库结构变更
