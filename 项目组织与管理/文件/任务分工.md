# 基于机器学习的零件智能分类与推荐系统 — 两周任务分工

> **项目组**：软件项目组织与管理 · 第19组  
> **开发周期**：2周（14天）  
> **团队规模**：8人（**6人开发** + **2人文档/测试**）  
> **项目目标**：完成课程答辩可用的 MVP —— CAD 上传 → 自动分类 → 相似件检索 → 3D 预览 → 聚类/可视化 → Excel 导出 → AI 分析助手

## 一、两周 MVP 范围说明

原报告规划为 6 个月，**2 周内必须做减法**。以下功能为**必做**（答辩合格线），其余为**选做**（时间充裕再做）。

| 优先级 | 功能模块 | 两周目标 |
|--------|----------|----------|
| P0 | 用户登录与三角色权限 | 设计工程师 / 管理员 / 采购工程师，JWT 登录 |
| P0 | CAD 上传（STEP、STL） | 上传、元数据入库、文件存储 |
| P0 | 特征提取 + 自动分类 | D2 形状分布 或 多视图 CNN 二选一，准确率 ≥85% 即可 |
| P0 | 相似件推荐（FAISS） | 5 秒内返回 Top-10 |
| P0 | 3D 模型预览 | Three.js 旋转/缩放/平移 |
| P0 | 零件列表与详情页 | 搜索、筛选、分类结果展示 |
| P1 | KMeans 聚类 + PCA/t-SNE 可视化 | 管理员页 ECharts 散点图 |
| P1 | Excel 导出 | 零件编号、类别、相似度、材料、库存 |
| P1 | AI 零件分析助手 | DeepSeek API，上传后生成文字分析 |
| P2 | AI 问答（RAG） | 时间够再做 |
| P2 | DWG/DXF 支持 | 时间够再做，优先 STEP/STL |
| 不做 | 完整 PointNet 自训练、3D-CNN 自训练 | 用预训练或传统特征替代 |

### 推荐技术栈（统一，禁止各自选型）

```text
前端：Vue3 + Element Plus + Three.js + ECharts + Axios
后端：FastAPI + Python 3.10+
数据库：MySQL 8.0
文件存储：本地 uploads/ 目录（两周内不上 MinIO）
AI：scikit-learn（SVM/随机森林）+ FAISS + numpy
CAD：trimesh / FreeCAD 命令行转 STL
大模型：DeepSeek API（或智谱/通义，由成员6开发并申请 Key）
协作：Git + 微信/腾讯文档 + 每晚站会 15 分钟
```

### 2.3 算法组并行开发说明（成员4 + 成员5）

成员4、成员5 **不需要串行等待**，第 1～5 天可完全并行，仅在少数节点对接。

#### 依赖关系

```text
成员4：数据 → 预处理 → 特征提取 → 分类
成员5：FAISS → 检索 → 聚类 → 降维可视化
              ↑
        交汇点：特征向量（格式 + 样例/全量数据）
```

#### 四个对接节点

| 节点 | 时间 | 成员4 交付 | 成员5 动作 |
|------|------|------------|------------|
| 接口约定 | 第 1 天 | 确定向量维度、归一化方式、存储格式 | 按约定编写检索框架 |
| 样例特征 | **第 3 天** | ≥10 个模型的真实特征向量 | 用样例建索引，跑通检索/聚类 |
| 全量特征 | 第 6～7 天 | 全部零件特征提取完成 | 重建 FAISS 全量索引 |
| 增量更新 | 第 8 天后 | 新上传零件触发特征提取 | 新特征自动写入索引 |

#### 第 1 天必须敲定的接口契约

```python

    """返回 shape=(512,) 的 float32 向量，L2 归一化"""

    """返回 (类别, 置信度)"""

# 成员5 提供
def build_index(features: np.ndarray, part_ids: list[str]) -> None:
    """用特征矩阵构建/重建 FAISS 索引"""

def search(query: np.ndarray, k: int = 10) -> list[dict]:
    """返回 [{part_id, similarity}, ...]"""
```

写入 `docs/ml_interface.md`，成员 1 据此挂载 API 路由。

#### 并行时间线

```text
时间    成员4（特征+分类）           成员5（检索+聚类）
──────────────────────────────────────────────────────
D1-2    数据集下载+标注              FAISS 框架+随机假向量联调
D3      ★交付≥10个样例特征★         用样例向量建索引、跑通 search
D4-5    特征提取+分类器训练          KMeans、PCA/t-SNE、检索 API 封装
D6-7    批量提取全量特征    ─对接→   全量重建索引，性能测试≤5秒
D8-10   上传触发特征+分类   ←对接→   新零件增量更新索引
D11-14  调参+混淆矩阵                检索优化+答辩案例
```

#### 避免互相阻塞的三条规矩

1. 成员5 **第 1～2 天用随机向量**先把 FAISS 逻辑写通，不坐等真实数据  
2. 成员4 **第 3 天必须交付样例特征**，不要求 100 个全标完  
3. 成员4 负责 `extract_features()`，成员5 负责 `search()`，**禁止跨边界改对方模块**
