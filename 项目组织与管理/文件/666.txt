根据你上传的《项目选题》和《软件项目组织与管理项目报告》，你们最终要做的并不是一个简单的“零件管理系统”，而是一个结合 CAD、机器学习、大模型辅助分析的工业智能系统。

从课程项目角度来看，如果只是完成老师要求，其实做到“CAD上传 + 自动分类 + 相似件检索 + 3D预览”就已经合格；但如果想做出亮点、参加比赛、答辩拿高分，那么接入大模型接口会让系统直接提升一个档次。

---

# 一、这个系统到底是干什么的？

项目名称：

**基于机器学习的零件智能分类与推荐系统**

核心目标：

解决企业零件库中的三个问题：

| 问题   | 现状        |
| ---- | --------- |
| 分类困难 | 工程师手工分类   |
| 搜索困难 | 只能搜编号和名称  |
| 重复设计 | 找不到已有相似零件 |

例如：

企业已经有一个支架：

```
Bracket_2023_001.step
```

新工程师设计了一个：

```
Bracket_new.step
```

实际上两者90%相似。

但传统系统发现不了。

于是：

* 重复建模
* 重复采购
* 库存增加
* 成本增加

你们系统就是：

> 上传零件 → 自动识别 → 自动分类 → 找出相似件 → 推荐复用

## 功能1 零件智能分析助手

接：

* OpenAI GPT
* DeepSeek
* Qwen
* 智谱GLM

用户上传零件后：

AI自动分析：

```text
该零件属于支架类零件。

主要特征：

1. 两个安装孔
2. L型结构
3. 板厚5mm

推荐工艺：

激光切割
折弯加工

推荐材料：

Q235钢板
```

这个功能答辩非常亮眼。

---

## 功能5 AI推荐替代件

传统系统：

```text
相似度95%
```

用户不知道为什么。

AI解释：

```text
推荐 gear001

原因：

1. 模数一致
2. 齿数接近
3. 外径差异小于3%

可直接替换
```

这属于可解释AI。

---

## 功能6 AI设计复用建议（最有创新性）

上传新零件：

AI发现：

```text
与已有零件重复度87%
```

提示：

```text
建议直接复用：

Gear_001

预计节省：

设计时间：
4小时

制造成本：
12%
```

这非常符合项目背景。
