## 二、实验原理

### 2.1 高斯滤波
高斯滤波是一种线性平滑滤波，适用于消除高斯噪声。高斯滤波器的核函数为：
```
G(x,y) = (1/2πσ²) * exp(-(x²+y²)/(2σ²))
```
其中σ为标准差，控制滤波器的宽度。

### 2.2 高斯拉普拉斯算子(LoG)
拉普拉斯算子是一种二阶导数算子，用于检测图像中的边缘。LoG算子通过先进行高斯平滑再应用拉普拉斯算子来减少噪声影响：
```
LoG(x,y) = (x²+y²-2σ²)/(2πσ⁶) * exp(-(x²+y²)/(2σ²))
```

### 2.3 Canny边缘检测算法
Canny边缘检测是一种多阶段的边缘检测算法：
1. 高斯滤波：平滑图像，去除噪声
2. 计算梯度：使用Sobel算子计算像素梯度的幅值和方向
3. 非极大值抑制：细化边缘，保留局部最大值
4. 双阈值检测：使用高低阈值连接边缘
5. 边缘连接：根据阈值连接边缘

### 2.4 评价指标
- 精确率(Precision) = TP / (TP + FP)
- 召回率(Recall) = TP / (TP + FN)
- F1分数 = 2 × (Precision × Recall) / (Precision + Recall)

其中TP(True Positive)为正确检测的边缘像素数，FP(False Positive)为错误检测的边缘像素数，FN(False Negative)为未检测到的边缘像素数。

## 三、实验结果及分析

### 3.1 任务一：滤波和边缘检测
在任务一中，实现了高斯滤波和高斯拉普拉斯边缘检测，参数设置如下：
- 窗口大小：3×3, 5×5, 7×7, 9×9, 11×11
- 尺度因子：1, 3, 5, 7

实验结果显示：
- 随着窗口尺寸增大，滤波效果更加平滑，但细节损失增加
- 随着尺度因子增大，边缘检测结果更加粗略，但噪声抑制效果更好
- 彩色图像需要对每个颜色通道分别处理，然后合并结果

### 3.2 任务二：Canny边缘检测
在任务二中，通过调整不同的高低阈值参数，观察Canny边缘检测效果：
- 低阈值：50, 100, 150
- 高阈值：100, 150, 200, 250

实验结果显示：
- 低阈值控制边缘连接的敏感性，值越低检测到的边缘越多，但噪声也越多
- 高阈值控制强边缘的检测，值越高只保留更强的边缘
- 合适的参数组合能平衡边缘检测的完整性和准确性

### 3.3 任务三：BSDS500数据集评估
在任务三中，使用BSDS500测试集评估Canny边缘检测性能：
- 选择了图像100007作为示例
- 与Ground Truth对比计算精确率、召回率和F1分数
- 最佳结果：精确率=0.053，召回率=0.277，F1分数=0.089

分析：
- 精确率较低说明检测到的边缘中有很多是错误的
- 召回率适中说明能检测到部分真实边缘
- F1分数较低说明整体性能有待提高
- 可能的改进方向包括：调整Canny参数、使用其他边缘检测算法、后处理等
