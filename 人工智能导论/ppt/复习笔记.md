# 人工智能导论复习笔记

## 第2章 知识表示与知识图谱

### 谓词公式的性质

#### 1. 谓词公式的解释
- **定义**: 谓词公式在个体域上的解释是个体域中的实体对谓词演算表达式的每个常量、变量、谓词和函数符号的指派
- **特点**: 对于每一个解释,谓词公式都可求出一个真值(T或F)

#### 2. 谓词公式的永真性、可满足性、不可满足性

**永真性**:
- 如果谓词公式P对个体域D上的任何一个解释都取得真值T,则称P在D上是永真的
- 如果P在每个非空个体域上均永真,则称P永真

**可满足性**:
- 对于谓词公式P,如果至少存在一个解释使得P在此解释下的真值为T,则称P是可满足的

**不可满足性**:
- 如果谓词公式P对个体域D上的任何一个解释都取得假值F,则称P在D上是永假的
- 如果P在每个非空个体域上均永假,则称P永假

#### 3. 谓词公式的等价性
- **定义**: 设P与Q是两个谓词公式,D是它们共同的个体域,若对D上的任何一个解释,P与Q都有相同的真值,则称公式P和Q在D上是等价的
- **常见等价关系**:
  - 否定之否定: ﹁(﹁P) 等价于 P
  - 蕴含式转化: P → Q 等价于 ﹁P ∨ Q
  - 德·摩根定律: ﹁(P ∨ Q) 等价于 ﹁P ∧ ﹁Q; ﹁(P ∧ Q) 等价于 ﹁P ∨ ﹁Q
  - 分配律: P ∧ (Q ∨ R) 等价于 (P ∧ Q) ∨ (P ∧ R)
  - 逆否律: P → Q 等价于 ﹁Q → ﹁P

#### 4. 量词转换律
- **量词否定**: 
  - ﹁(∃x)P(x) 等价于 (∀x)[﹁P(x)]
  - ﹁(∀x)P(x) 等价于 (∃x)[﹁P(x)]
- **量词分配**:
  - (∀x)[P(x) ∧ Q(x)] 等价于 (∀x)P(x) ∧ (∀x)Q(x)
  - (∃x)[P(x) ∨ Q(x)] 等价于 (∃x)P(x) ∨ (∃x)Q(x)

#### 5. 谓词公式的永真蕴含
- **定义**: 对于谓词公式P与Q,如果P → Q永真,则称公式P永真蕴含Q,且称Q为P的逻辑结论,称P为Q的前提,记为 P ⇒ Q
- **常用推理规则**:
  - 假言推理: P, P → Q ⇒ Q
  - 拒取式推理: P → Q, ﹁Q ⇒ ﹁P
  - 假言三段论

#### 6. 谓词逻辑的其他推理规则
- **P规则**: 在推理的任何步骤上都可引入前提
- **T规则**: 在推理过程中,如果前面步骤中有一个或多个公式永真蕴含公式S,则可把S引入推理过程中
- **CP规则**: 如果能从任意引入的命题R和前提集合中推出S来,则可从前提集合推出R → S来
- **反证法**: Q为P的逻辑结论,当且仅当(P ∧ ﹁Q)是不可满足的

### 置换与合一

#### 1. 置换
- **定义**: 置换是形如 {t1/x1, t2/x2, ..., tn/xn} 的有限集合,其中ti是项,xi是变量
- **作用**: 将表达式中的变量xi替换为项ti
- **例子**: 置换 {z/x, w/y} 作用于 P[x, f(y), B] 得到 P[z, f(w), B]

#### 2. 合一
- **定义**: 寻找项对变量的置换,以使两表达式一致
- **可合一**: 如果存在一个置换s,使得E₁s = E₂s = ... = Eₙs,则称表达式集{Ei}是可合一的
- **合一者**: 使集合{Ei}成为单一形式的置换s
- **例子**: 表达式集{P[x, f(y), B], P[x, f(B), B]}的合一者为 {A/x, B/y}

## 第3章 确定性推理方法

### 归结演绎推理（重点难点）

#### 1. 归结反演

**定义**: 应用归结原理证明定理的过程称为归结反演

**步骤**:
1. 将已知前提表示为谓词公式F
2. 将待证明的结论表示为谓词公式Q,并否定得到﹁Q
3. 把谓词公式集{F,﹁Q}化为子句集S
4. 应用归结原理对子句集S中的子句进行归结,并把每次归结得到的归结式都并入到S中。如此反复进行,若出现了空子句,则停止归结,此时就证明了Q为真

**核心思想**: 反证法
- Q为P₁, P₂, ..., Pₙ的逻辑结论,当且仅当(P₁ ∧ P₂ ∧ ... ∧ Pₙ ∧ ﹁Q)是不可满足的
- 如果子句集是不可满足的,则必存在一个从该子句集到空子句的归结演绎
- 若从子句集存在一个到空子句的演绎,则该子句集是不可满足的

#### 2. 谓词公式化为子句集的方法

**基本概念**:
- **原子**: 不能再分解的命题
- **文字**: 原子谓词公式及其否定
- **子句**: 任何文字的析取式
- **空子句(NIL)**: 不包含任何文字的子句,是永假的,不可满足的
- **子句集**: 由子句构成的集合

**九个步骤**:

1. **消去蕴含和等价符号**
   - P → Q 替换为 ﹁P ∨ Q
   - P ⇔ Q 替换为 (P → Q) ∧ (Q → P)

2. **减少否定符号﹁的辖域**
   - 以﹁A ∨ ﹁B代替﹁(A ∧ B)
   - 以﹁A ∧ ﹁B代替﹁(A ∨ B)
   - 以(∃x){﹁A}代替﹁(∀x)A
   - 以(∀x){﹁A}代替﹁(∃x)A
   - 以A代替﹁(﹁A)

3. **对变量标准化**
   - 在任一量词辖域内,受该量词约束的变量为一哑元,可以在该辖域内处处统一地被另一个没有出现过的任意变量所代替
   - 例如:(∀x){P(x) → (∃x)Q(x)}标准化得到:(∀x){P(x) → (∃y)Q(y)}

4. **消去存在量词**
   - **Skolem函数**: 如果要消去的存在量词在某些全称量词的辖域内,令存在的x可能依赖于y值,用函数g(y)定义
   - 例如:(∀y)[(∃x)P(x,y)]化为(∀y)P(g(y),y)
   - 如果存在量词不在任何一个全称量词的辖域内,则使用不含变量的Skolem函数即常量
   - 例如:(∃x)P(x)化为P(A)

5. **化为前束形**
   - 把所有全称量词移到公式的左边,并使每个量词的辖域包括这个量词后面公式的整个部分
   - 前束形 = (前缀)(母式)
   - 前缀 = 全称量词串
   - 母式 = 无量词公式

6. **把母式化为合取范式**
   - 反复应用分配律,把任一母式化成合取范式
   - 例如:A ∨ {B ∧ C}化为{A ∨ B} ∧ {A ∨ C}

7. **消去全称量词**
   - 消去前缀,即消去明显出现的全称量词

8. **消去合取符号∧**
   - 用{(A ∨ B), (A ∨ C)}代替(A ∨ B) ∧ (A ∨ C)

9. **更换变量名称**
   - 更换变量符号的名称,使一个变量符号不出现在一个以上的子句中

**定理**: 谓词公式不可满足的充要条件是其子句集不可满足

#### 3. 鲁宾逊归结原理

**基本思想**:
- 检查子句集S中是否包含空子句,若包含,则S不可满足
- 若不包含,在S中选择合适的子句进行归结,一旦归结出空子句,就说明S是不可满足的

**命题逻辑中的归结原理**:
- **定义**: 设C₁与C₂是子句集中的任意两个子句,如果C₁中的文字L₁与C₂中的文字L₂互补,那么从C₁和C₂中分别消去L₁和L₂,并将二个子句中余下的部分析取,构成一个新子句C₁₂
- **例子**: P ∨ ﹁Q 和 Q ∨ ﹁R 归结得到 P ∨ ﹁R
- **推论1**: 用C₁₂代替C₁与C₂后得到新子句集S₁,则由S₁不可满足性可推出原子句集S的不可满足性
- **推论2**: C₁₂加入原子句集S,得到新子句集S₁,则S与S₁在不可满足的意义上是等价的
- **定理**: 归结式C₁₂是其亲本子句C₁与C₂的逻辑结论

**谓词逻辑中的归结原理**:
- **定义**: 设C₁和C₂是两个没有相同变元的子句,L₁和L₂分别是C₁和C₂中的文字,若σ是{L₁, ﹁L₂}的最一般合一,则称C₁₂为C₁和C₂的二元归结式
- **例子**: C₁ = P[x, f(y), B], C₂ = ﹁P[A, f(B), B],则二元归结式为 Q[y, R, A]
- **性质**: 对于一阶谓词逻辑,即若子句集是不可满足的,则必存在一个从该子句集到空子句的归结演绎

### 可信度方法（重点！！）

#### 1. 知识不确定性的表示

**产生式规则表示**: `IF E THEN H (CF(H, E))`
- CF(H, E): 可信度因子,反映前提条件与结论的联系强度

**CF(H, E)的取值范围**: [-1, 1]
- CF(H, E) > 0: 证据的出现支持H为真
- CF(H, E) < 0: 证据的出现支持H为假
- CF(H, E) = 0: 证据的出现与H无关

#### 2. 证据不确定性的表示

**CF(E)的取值范围**: [-1, 1]
- CF(E) = 1: 肯定为真
- CF(E) = -1: 肯定为假
- 0 < CF(E) < 1: 以某种程度为真
- -1 < CF(E) < 0: 以某种程度为假
- CF(E) = 0: 未获得任何相关信息

#### 3. 组合证据不确定性的算法

**合取**: E = E₁ AND E₂ AND ... AND Eₙ
- CF(E) = min{CF(E₁), CF(E₂), ..., CF(Eₙ)}

**析取**: E = E₁ OR E₂ OR ... OR Eₙ
- CF(E) = max{CF(E₁), CF(E₂), ..., CF(Eₙ)}

#### 4. 不确定性的传递算法

**C-F模型中的不确定性推理**:
```
CF(H) = max{0, CF(E)} × CF(H, E)
```

**特殊情况**:
- 当CF(E) ≤ 0时,则CF(H) = 0
- 当CF(E) = 1时,则CF(H) = CF(H, E)

#### 5. 结论不确定性的合成算法

**步骤**:
1. 分别对每一条知识求出CF(H):
   ```
   CF₁(H) = max{0, CF(E₁)} × CF(H, E₁)
   CF₂(H) = max{0, CF(E₂)} × CF(H, E₂)
   ```

2. 求出CF₁与CF₂对H的综合影响所形成的可信度CF₁,₂(H):

**当CF₁和CF₂同号时**:
```
CF₁,₂ = CF₁ + CF₂ - CF₁ × CF₂
```

**当CF₁和CF₂异号时**:
```
CF₁,₂ = (CF₁ + CF₂) / (1 - min{|CF₁|, |CF₂|})
```

### 证据理论（D-S理论）

#### 核心概念（重点！！）

**概率分配函数M**:
- 定义: 设函数M: 2ᴰ → [0, 1],且满足M(Φ) = 0, ΣA⊆D M(A) = 1
- M(A): A的基本概率数,对相应命题A的精确信任度
- 注意: 概率分配函数与概率不同

**信任函数Bel(A)**:
- 定义: Bel(A) = ΣB⊆A M(B)
- 含义: 对A为真的总的信任程度(A的所有子集的信任度之和)

**似然函数Pl(A)**:
- 定义: Pl(A) = 1 - Bel(¬A)
- 含义: 对A非假的总的信任程度(与A相交的子集的信任度之和)

**证据组合**:
- 通过正交和运算合并来自不同源的证据
- 定义: 设M₁和M₂是两个概率分配函数,则其正交和M = M₁ ⊕ M₂
- 计算公式:
  ```
  K = Σx∩y=Φ M₁(x)M₂(y)
  M(A) = (1/K)Σx∩y=A M₁(x)M₂(y)
  ```
- 如果K = 0,则不存在正交和M,即M₁与M₂矛盾

### 模糊集合运算、代数运算（重点！！）

#### 1. 模糊集合的交并补运算

**交运算**:
```
(A ∩ B)(x) = min{A(x), B(x)}
```

**并运算**:
```
(A ∪ B)(x) = max{A(x), B(x)}
```

**补运算**:
```
Aᶜ(x) = 1 - A(x)
```

#### 2. 模糊集合的代数运算

**代数积**:
```
(A · B)(x) = A(x) × B(x)
```

**代数和**:
```
(A + B)(x) = A(x) + B(x) - A(x) × B(x)
```

**有界和**:
```
(A ⊕ B)(x) = min{1, A(x) + B(x)}
```

**有界积**:
```
(A ⊗ B)(x) = max{0, A(x) + B(x) - 1}
```

### 模糊关系合成、模糊推理、模糊决策

#### 1. 模糊关系合成

**定义**: 从X到Y的模糊关系R,用模糊矩阵表示

**合成运算**: S = R ∘ Q
- 计算方法: S(x,z) = max min{R(x,y), Q(y,z)}

#### 2. 模糊推理

**IF A THEN B类型的模糊规则**:
- 已知输入为A,则输出为B
- 若现在已知输入为A',则输出B'用合成规则求取:
  ```
  B' = A' ∘ R
  ```
- 模糊关系R: R(x,y) = min{A(x), B(y)}

#### 3. 模糊决策

**最大隶属度法**:
- 选取隶属度最大的元素作为决策结果

**加权平均判决法**:
```
U* = Σμ(ui) × ui / Σμ(ui)
```

**中位数法**:
- 选取使累积隶属度达到0.5的元素作为决策结果

## 第7章 专家系统与机器学习

### 专家系统的概念

#### 1. 专家系统的定义

**费根鲍姆定义**: "专家系统是一种智能的计算机程序,它运用知识和推理来解决只有专家才能解决的复杂问题。"

**专家系统**: 一类包含知识和推理的智能计算机程序

#### 2. 专家系统的基本组成

- **知识库**: 存储领域知识
- **推理机**: 控制推理过程
- **数据库**: 存储事实和中间结果
- **解释程序**: 解释推理过程
- **知识获取**: 获取和更新知识
- **调度程序**: 控制系统运行

#### 3. 专家系统的特点

1. **具有专家水平的专业知识**
2. **能进行有效的推理**
3. **具有启发性**
4. **具有灵活性**
5. **具有透明性**
6. **具有交互性**

#### 4. 专家系统与传统程序的比较

1. **编程思想**:
   - 传统程序 = 数据结构 + 算法
   - 专家系统 = 知识 + 推理

2. **知识表示**:
   - 传统程序: 知识隐含于程序中
   - 专家系统: 知识单独组成知识库,与推理机分离

3. **处理对象**:
   - 传统程序: 数值计算和数据处理
   - 专家系统: 符号处理

4. **解释功能**:
   - 传统程序: 不具有解释功能
   - 专家系统: 具有解释功能

5. **输出**:
   - 传统程序: 产生正确的答案
   - 专家系统: 通常产生正确的答案,有时产生错误的答案

### 机器学习的基本概念和分类

#### 1. 机器学习的基本概念

**定义**: 机器学习使计算机能模拟人的学习行为,自动地通过学习来获取知识和技能,不断改善性能,实现自我完善

**学习系统的基本结构**:
- 环境
- 学习
- 知识库
- 执行与评价

#### 2. 机器学习的分类

**按学习方法分类**:
- 机械式学习
- 指导式学习
- 示例学习
- 类比学习
- 解释学习

**按学习能力分类**:
- **监督学习(有教师学习)**: 有标签的训练数据
- **强化学习(再励学习或增强学习)**: 通过奖励和惩罚学习
- **非监督学习(无教师学习)**: 无标签的训练数据

**按推理方式分类**:
- 基于演绎的学习(解释学习)
- 基于归纳的学习(示例学习、发现学习等)

**按综合属性分类**:
- 归纳学习
- 分析学习
- 连接学习
- 遗传式学习

#### 3. 主要学习方法

**机械式学习**:
- 又称记忆学习或死记式学习
- 通过直接记忆或者存储外部环境所提供的信息达到学习的目的
- 实质是用存储空间来换取处理时间
- 典型例子: 塞缪尔的跳棋程序CHECKERS

**指导式学习**:
- 又称嘱咐式学习或教授式学习
- 由外部环境向系统提供一般性的指示或建议
- 系统把它们具体地转化为细节知识并送入知识库中
- 学习过程: 征询指导者的指示或建议、把征询意见转换为可执行的内部形式、加入知识库、评价

**示例学习**:
- 通过从环境中取得若干与某概念有关的例子,经归纳得出一般性概念
- 外部环境提供一组例子(正例和反例)
- 从这些特殊知识中归纳出适用于更大范围的一般性知识

## 第8章 人工神经网络及其应用

### 卷积网络中的关键技术

#### 1. 局部连接

- **全连接神经网络**: 每个神经元都与上一层所有神经元连接
- **局部连接神经网络**: 每个神经元只与上一层的局部区域连接
- **优点**: 减少参数数量,提取局部特征

#### 2. 权值共享

- 同一特征映射图上的神经元共享相同的权值
- **优点**: 大大减少了参数数量
- **例子**: 100个权值可以替代大量全连接的参数

#### 3. 多卷积核

- 使用多个不同的卷积核来提取不同的特征
- 每个卷积核可以提取一种特定的特征
- **优点**: 提取多种特征,提高表达能力

#### 4. 池化

**目的**: 对不同位置的特征进行聚合统计

**常用方法**:
- **平均池化**: 计算区域内的平均值
- **最大池化**: 计算区域内的最大值

**作用**:
- 降低空间分辨率
- 对输入微小变化具有不变性
- 减少参数数量,防止过拟合

### 深度学习模型分类

#### 判别式模型
- **定义**: 将高维的感官输入映射为类别标签
- **特点**: 判断输入属于哪个类别
- **应用**: 分类、检测等任务
- **现状**: 目前深度学习取得的成果主要集中在判别式模型

#### 生成式模型
- **定义**: 将随机点变成与数据集相似的图片
- **特点**: 学习数据的分布,生成新的样本
- **挑战**:
  - 需要大量先验知识对真实世界建模
  - 计算量庞大
- **代表**: 生成对抗网络(GAN)

**生成对抗网络(GAN)**:
- 2014年Goodfellow等人提出
- 使用对抗训练机制对两个神经网络进行训练
- **两个网络**:
  - 生成网络: 生成假样本
  - 判别网络: 区分真假样本
- **训练过程**: 两个网络相互对抗,各自网络参数不断调整
- **应用**: 图像生成、图像修复、风格迁移等
