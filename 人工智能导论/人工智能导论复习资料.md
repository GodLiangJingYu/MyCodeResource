# 人工智能导论复习资料

## 第1章 绪论

### 1.1 人工智能的基本概念

#### 1.1.1 智能的概念与特征

**智能的定义：**
- 获取知识并应用知识求解问题的能力
- 智能是知识与智力的总和，知识是一切智能行为的基础

**智能的特征：**

1. **感知能力**
   - 通过视觉、听觉、触觉、嗅觉等感觉器官感知外部世界的能力
   - 是智能的前提与必要条件
   - 80%以上信息通过视觉得到，10%信息通过听觉得到

2. **记忆与思维能力**
   - 是有智能的根本原因
   - 思维方式：
     - 抽象思维（逻辑思维）：根据逻辑规则对信息和知识进行处理
     - 形象思维（直感思维）：基于形象概念，根据感性形象认识材料处理
     - 灵感思维（顿悟思维）：显意识和潜意识相互作用的思维方式

3. **学习和自适应能力**
   - 学习：具有特定目的的知识获取过程，是人的本能
   - 自适应：通过自我调节适应外界环境的过程

4. **行为能力（表达能力）**
   - 对感知到的外界信息作出动作反应的能力
   - 实现过程：
     - 感知-动作方式：对简单、紧急信息
     - 感知-思维-动作方式：对复杂信息

#### 1.1.2 人工智能的定义

**人工智能（Artificial Intelligence）：**
- 用人工的方法在机器（计算机）上实现的智能或使机器具有类似于人的智能
- 人工智能 = 机器智能 = 模拟智能

**人工智能学科：**
- 一门研究如何构造智能机器（智能计算机）或智能系统，以模拟、延伸、扩展人类智能的学科

#### 1.1.3 人工智能的研究目标

**图灵测试（1950年）：**
- 通过让机器模仿人回答某些问题，判断它是否具备智能

**近期目标：**
- 使现有的电子数字计算机更聪明、更有用
- 能运用知识处理问题，能模拟人类的部分智能行为

**远期目标：**
- 构造智能计算机
- 揭示人类智能的根本机理，用智能机器去模拟、延伸和扩展人类的智能

### 1.2 人工智能的发展简史

#### 1.2.1 孕育期（1956年之前）

**符号主义学派：**
- 亚里士多德（公元前384－322）：创立了演绎法，提出了演绎推理的一般原则——三段论
- 莱布尼茨（1646－1716）：把形式逻辑符号化，奠定了数理逻辑的基础

**连接主义学派：**
- 1890年美国生物学家詹姆斯首次阐明人脑的结构及功能
- 1943年美国神经生理学家麦克洛奇和皮茨建成第一个神经网络模型（MP模型）
- 1949年加拿大心理学家赫布提出了改变神经网络连接强度的Hebb规则

**行为主义学派：**
- 维纳（1874—1956）：1948年创立了控制论

**计算机的诞生：**
- 1946年研制成功世界上第一台通用电子计算机ENIAC

**图灵的贡献：**
- 1936年创立了自动机理论（图灵机）
- 1950年在《计算机与智能》中首次提出"机器也能思维"
- 设计了"图灵试验"，被誉为"人工智能之父"

#### 1.2.2 形成期（1956~1969）

**AI的诞生：**
- 时间：1956年夏季
- 地点：达特莫斯（Dartmouth）大学
- 发起人：麦卡锡、明斯基、洛切斯特、香农
- 由麦卡锡提议正式采用了"Artificial Intelligence"这一术语

**早期研究：**
- 1957年：纽厄尔、肖和西蒙研制了逻辑理论机（LT）
- 1960年：研制了通用问题求解程序
- 1956年：塞缪尔研制了西洋跳棋程序
- 1965年：鲁宾逊提出了归结（消解）原理

#### 1.2.3 发展阶段

**第一次低谷（1974－1980）：**
- 失败的预言和挫折
- 以知识为中心的研究：专家系统（MYCIN、PROSPECTOR）

**黄金时期（1981－1987）：**
- AI被引入市场，显示出实用价值
- 日本第五代计算机项目
- 英国的Alvey工程
- 美国DARPA对AI的投资大幅增加

**第二次低谷（1987-1993）：**
- 最初大获成功的专家系统维护费用居高不下
- 日本的"第五代工程"没有实现

**平稳发展期（1994-2011）：**
- 1997年："深蓝"战胜国际象棋世界冠军卡斯帕罗夫
- 2000年：本田公司发布机器人产品ASIMO
- 2011年：IBM开发的"沃森"（Watson）参加智力问答节目并战胜人类冠军

**蓬勃发展期（2012－至今）：**
- 专用人工智能有突破性进展
- "智能+"成为人工智能应用的创新模式
- 人工智能领域的国际竞争日益激烈

## 第2章 知识表示与知识图谱

### 2.1 知识与知识表示的概念

#### 2.1.1 知识的概念

**知识：**
- 在长期的生活及社会实践中、在科学研究及实验中积累起来的对客观世界的认识与经验
- 把有关信息关联在一起所形成的信息结构

**知识的特性：**

1. **相对正确性**
   - 任何知识都是在一定的条件及环境下产生的
   - 例如：1+1=2（十进制），1+1=10（二进制）

2. **不确定性**
   - 随机性引起的不确定性
   - 模糊性引起的不确定性
   - 经验引起的不确定性
   - 不完全性引起的不确定性

3. **可表示性与可利用性**
   - 知识可以用适当形式表示出来
   - 知识可以被利用

#### 2.1.2 知识的表示

**知识表示（knowledge representation）：**
- 将人类知识形式化或者模型化
- 是对知识的一种描述，或者说是一组约定，一种计算机可以接受的用于描述知识的数据结构

**选择知识表示方法的原则：**
1. 充分表示领域知识
2. 有利于对知识的利用
3. 便于对知识的组织、维护与管理
4. 便于理解与实现

### 2.2 一阶谓词逻辑表示法

#### 2.2.1 命题

**命题（proposition）：**
- 一个非真即假的陈述句
- 命题的真值为真，记为T；为假，记为F

#### 2.2.2 谓词

**谓词的一般形式：**
```
P(x1, x2, …, xn)
```
- 谓词名P：刻画个体的性质、状态或个体间的关系
- 个体x1, x2, …, xn：某个独立存在的事物或某个抽象的概念

**示例：**
- "老张是一个教师"：Teacher(Zhang) —— 一元谓词
- "5 > 3"：Greater(5, 3) —— 二元谓词
- "Smith作为一个工程师为IBM工作"：Works(Smith, IBM, engineer) —— 三元谓词

#### 2.2.3 谓词公式

**1. 连接词（连词）：**
- ¬：否定
- ∨：析取（或）
- ∧：合取（与）
- →：蕴含（条件）
- ↔：等价（双条件）

**2. 量词（quantifier）：**
- 全称量词∀x："对个体域中的所有（或任一个）个体x"
- 存在量词∃x："在个体域中存在个体x"

**3. 谓词公式定义：**
(1) 单个谓词是谓词公式，称为原子谓词公式
(2) 若A是谓词公式，则¬A也是谓词公式
(3) 若A，B都是谓词公式，则A∧B，A∨B，A→B，A↔B也都是谓词公式
(4) 若A是谓词公式，则(∀x)A，(∃x)A也是谓词公式
(5) 有限步应用（1）－（4）生成的公式也是谓词公式

**4. 量词的辖域：**
- 量词的辖域：位于量词后面的单个谓词或者用括号括起来的谓词公式
- 约束变元：辖域内与量词中同名的变元
- 自由变元：不同名的变元

#### 2.2.4 谓词公式的性质

**1. 谓词公式的解释：**
- 谓词公式在个体域上的解释：个体域中的实体对谓词演算表达式的每个常量、变量、谓词和函数符号的指派

**2. 谓词公式的永真性、可满足性、不可满足性：**
- 永真：谓词公式P对个体域D上的任何一个解释都取得真值T
- 可满足：至少存在一个解释使得P在此解释下的真值为T
- 不可满足：不可满足

**3. 谓词公式的等价性：**
- 设P与Q是两个谓词公式，若对D上的任何一个解释，P与Q都有相同的真值，则称公式P和Q在D上是等价的
- 重要等价律：
  - 否定之否定：¬(¬P)等价于P
  - 蕴含式转化：P→Q等价于¬P∨Q
  - 德·摩根定律：¬(P∨Q)等价于¬P∧¬Q；¬(P∧Q)等价于¬P∨¬Q
  - 分配律、交换律、结合律、逆否律

**4. 量词转换律：**
- 量词否定：¬(∃x)P(x)等价于(∀x)[¬P(x)]
- 量词分配：(∀x)[P(x)∧Q(x)]等价于(∀x)P(x)∧(∀x)Q(x)

**5. 谓词公式的永真蕴含：**
- 对于谓词公式P与Q，如果P→Q永真，则称公式P永真蕴含Q

#### 2.2.5 一阶谓词逻辑知识表示方法

**谓词公式表示知识的步骤：**
1. 定义谓词及个体
2. 变元赋值
3. 用连接词连接各个谓词，形成谓词公式

#### 2.2.6 一阶谓词逻辑表示法的特点

**优点：**
1. 自然性
2. 精确性
3. 严密性
4. 容易实现

**局限性：**
1. 不能表示不确定的知识
2. 组合爆炸
3. 效率低

### 2.3 产生式表示法

#### 2.3.1 产生式

**产生式：**
- 通常用于表示事实、规则以及它们的不确定性度量
- 适合于表示事实性知识和规则性知识

**1. 确定性规则知识的产生式表示：**
```
IF P THEN Q
```

**2. 不确定性规则知识的产生式表示：**
```
IF P THEN Q (置信度)
```

**3. 确定性事实性知识的产生式表示：**
- 三元组表示：（对象，属性，值）或（关系，对象1，对象2）
- 示例：（Li，age，40）

**4. 不确定性事实性知识的产生式表示：**
- 四元组表示：（对象，属性，值，置信度）
- 示例：（Li，age，40，0.8）

#### 2.3.2 产生式系统

**产生式系统的基本结构：**
```
综合数据库
    ↓
推理机 ←→ 规则库
    ↓
  控制系统
```

- **规则库**：用于描述相应领域内知识的产生式集合
- **综合数据库**：存放问题求解过程中各种当前信息的数据结构
- **推理机**：由一组程序组成，负责整个产生式系统的运行

#### 2.3.3 产生式系统——动物识别系统

**规则库示例：**
```
r1: IF 该动物有毛发 THEN 该动物是哺乳动物
r2: IF 该动物有奶 THEN 该动物是哺乳动物
r3: IF 该动物有羽毛 THEN 该动物是鸟
r4: IF 该动物会飞 AND 会下蛋 THEN 该动物是鸟
r5: IF 该动物吃肉 THEN 该动物是食肉动物
r6: IF 该动物有犬齿 AND 有爪 AND 眼盯前方 THEN 该动物是食肉动物
r7: IF 该动物是哺乳动物 AND 有蹄 THEN 该动物是有蹄类动物
r8: IF 该动物是哺乳动物 AND 是反刍动物 THEN 该动物是有蹄类动物
r9: IF 该动物是哺乳动物 AND 是食肉动物 AND 是黄褐色 AND 身上有暗斑点 THEN 该动物是金钱豹
r10: IF 该动物是哺乳动物 AND 是食肉动物 AND 是黄褐色 AND 身上有黑色条纹 THEN 该动物是虎
r11: IF 该动物是有蹄类动物 AND 有长脖子 AND 有长腿 AND 身上有暗斑点 THEN 该动物是长颈鹿
r12: IF 该动物是有蹄类动物 AND 身上有黑色条纹 THEN 该动物是斑马
r13: IF 该动物是鸟 AND 有长脖子 AND 有长腿 AND 不会飞 AND 有黑白二色 THEN 该动物是鸵鸟
r14: IF 该动物是鸟 AND 会游泳 AND 不会飞 AND 有黑白二色 THEN 该动物是企鹅
r15: IF 该动物是鸟 AND 善飞 THEN 该动物是信天翁
```

#### 2.3.4 产生式表示法的特点

**优点：**
1. 自然性
2. 模块性
3. 有效性
4. 清晰性

**缺点：**
1. 效率不高
2. 不能表达结构性知识

**适合产生式表示的知识：**
1. 领域知识间关系不密切，不存在结构关系
2. 经验性及不确定性的知识
3. 领域问题的求解过程可被表示为一系列相对独立的操作

### 2.4 框架表示法

**框架（frame）：**
- 一种描述所论对象属性的数据结构
- 一个框架由若干个被称为"槽"（slot）的结构组成，每一个槽又可根据实际情况划分为若干个"侧面"（faced）

**框架的一般结构：**
```
<框架名>
槽名1： 侧面名11  侧面值111，…，侧面值11P1
        ┊
        侧面名1m  侧面值1m1，…，侧面值1mPm
槽名n： 侧面名n1  侧面值n11，…，侧面值n1P1
        ┊
        侧面名nm  侧面值nm1，…，侧面值nmPm
约束：  约束条件1
        ┊
        约束条件n
```

#### 2.4.1 用框架表示知识的例子

**教师框架：**
```
框架名：〈教师〉
姓名：单位（姓、名）
年龄：单位（岁）
性别：范围（男、女）
     缺省：男
职称：范围（教授，副教授，讲师，助教）
     缺省：讲师
部门：单位（系，教研室）
住址：〈住址框架〉
工资：〈工资框架〉
开始工作时间：单位（年、月）
截止时间：单位（年，月）
          缺省：现在
```

#### 2.4.2 框架表示法的特点

1. **结构性**：便于表达结构性知识
2. **继承性**：下层框架可以继承上层框架的槽值
3. **自然性**：与人在观察事物时的思维活动一致

### 2.5 知识图谱

#### 2.5.1 知识图谱的定义

**知识图谱（Knowledge Graph）：**
- 一种互联网环境下的知识表示方法
- 由一些相互连接的实体及其属性构成

**三元组表示：**
- (实体1-关系-实体2)：中国-首都-北京
- (实体-属性-属性值)：北京-人口-2069万

#### 2.5.2 知识图谱的架构

**1. 逻辑结构：**
- 模式层：知识图谱的核心
- 数据层：主要由一系列的事实组成

**2. 体系架构：**
- 知识获取
- 知识融合
- 知识加工
- 知识应用

#### 2.5.3 知识图谱的构建

**获取知识的资源对象：**
- 结构化数据
- 半结构化数据
- 非结构化数据

#### 2.5.4 知识图谱的典型应用

1. **语义搜索**
2. **知识问答**
3. **大数据分析**
4. **社交网络**
5. **辅助语言理解**
6. **数字商业**

## 第3章 确定性推理方法

### 3.1 推理的基本概念

#### 3.1.1 推理的定义

**推理：**
- 从已知事实（证据）出发，通过运用相关知识逐步推出结论的某种策略

#### 3.1.2 推理方式及其分类

**1. 演绎推理、归纳推理、默认推理**

**演绎推理：** 一般→个别
- 三段论式
- 示例：
  - 大前提：足球运动员的身体都是强壮的
  - 小前提：高波是一名足球运动员
  - 结论：所以，高波的身体是强壮的

**归纳推理：** 个别→一般
- 完全归纳推理（必然性推理）
- 不完全归纳推理（非必然性推理）

**默认推理：**
- 知识不完全的情况下假设某些条件已经具备所进行的推理

**2. 确定性推理、不确定性推理**
- 确定性推理：推理时所用的知识与证据都是确定的
- 不确定性推理：推理时所用的知识与证据不都是确定的

**3. 单调推理、非单调推理**
- 单调推理：随着推理向前推进及新知识的加入，推出的结论越来越接近最终目标
- 非单调推理：由于新知识的加入，不仅要否定已推出的结论

**4. 启发式推理、非启发式推理**
- 启发式推理：运用启发性知识，加快推理过程，提高搜索效率

#### 3.1.3 推理的方向

**1. 正向推理（事实驱动推理）：**
- 已知事实→结论
- 基本思想：
  1. 从初始已知事实出发，在知识库中找出当前可适用的知识
  2. 按某种冲突消解策略从可适用知识集中选出一条知识进行推理
  3. 将推出的新事实加入到数据库中作为下一步推理的已知事实
  4. 重复直到求得问题的解或知识库中再无可适用的知识

**2. 逆向推理（目标驱动推理）：**
- 以某个假设目标作为出发点
- 优点：目的性强，利于向用户提供解释
- 缺点：起始目标的选择具有盲目性

**3. 混合推理：**
- 先正向后逆向
- 先逆向后正向

**4. 双向推理：**
- 正向推理与逆向推理同时进行，在推理过程中的某一步骤上"碰头"

#### 3.1.4 冲突消解策略

**多种冲突消解策略：**
1. 按就近原则排序
2. 按已知事实的新鲜性排序
3. 按匹配度排序
4. 按知识差异性排序
5. 按条件个数排序

### 3.2 自然演绎推理

**推理规则：**
- 假言推理：P, P→Q ⇒ Q
- 拒取式推理：P→Q, ¬Q ⇒ ¬P

**常见的推理错误：**
- 否定前件：P→Q, ¬P ⇒ ¬Q（错误）
- 肯定后件：P→Q, Q ⇒ P（错误）

### 3.3 谓词公式化为子句集的方法

**基本概念：**
- 原子：不能再分解的命题
- 文字：原子谓词公式及其否定
- 子句：任何文字的析取式
- 空子句（NIL）：不包含任何文字的子句
- 子句集：由子句构成的集合

**化简子句集的九个步骤：**
1. 消去蕴含和等价符号
2. 减少否定符号¬的辖域
3. 对变量标准化
4. 消去存在量词（Skolem函数）
5. 化为前束形
6. 把母式化为合取范式
7. 消去全称量词
8. 消去合取符号∧
9. 更换变量名称

### 3.4 鲁宾逊归结原理

**基本思想：**
- 检查子句集S中是否包含空子句，若包含，则S不可满足
- 若不包含，在S中选择合适的子句进行归结，一旦归结出空子句，就说明S是不可满足的

#### 3.4.1 命题逻辑中的归结原理

**定义（归结）：**
- 设C1与C2是子句集中的任意两个子句
- 如果C1中的文字L1与C2中的文字L2互补，那么从C1和C2中分别消去L1和L2，并将二个子句中余下的部分析取，构成一个新的子句C12

**推论：**
1. 归结式C12是其亲本子句C1与C2的逻辑结论
2. 若用C12替代C1与C2后得到新子句集S1，则S1在不可满足的意义上等价于S

#### 3.4.2 谓词逻辑中的归结原理

**定义（二元归结式）：**
- 设C1和C2是没有相同变元的两个子句，L1和L2分别是C1和C2中的文字
- 若σ是{L1, ¬L2}的最一般合一，则称C12为C1和C2的二元归结式

### 3.5 归结反演

**用归结反演证明的步骤：**
1. 将已知前提表示为谓词公式F
2. 将待证明的结论表示为谓词公式Q，并否定得到¬Q
3. 把谓词公式集{F，¬Q}化为子句集S
4. 应用归结原理对子句集S中的子句进行归结
5. 若出现了空子句，则停止归结，此时就证明了Q为真

### 3.6 应用归结反演求解问题

**应用归结原理求解问题的步骤：**
1. 已知前提F用谓词公式表示，并化为子句集S
2. 把待求解的问题Q用谓词公式表示，并否定Q，再与ANSWER构成析取式（¬Q∨ANSWER）
3. 把（¬Q∨ANSWER）化为子句集，并入到子句集S中，得到子句集S'
4. 对S'应用归结原理进行归结
5. 若得到归结式ANSWER，则答案就在ANSWER中

## 第4章 不确定性推理方法

### 4.1 不确定性推理的基本问题

**不确定性推理：**
- 从不确定性的初始证据出发，通过运用不确定性的知识，最终推出具有一定程度的不确定性但却是合理的结论的推理过程

**需要解决的基本问题：**
1. 不确定性的表示与量度
2. 不确定性匹配算法及阈值的选择
3. 组合证据不确定性的算法
4. 不确定性的传递算法
5. 结论不确定性的合成

### 4.2 可信度方法

#### 4.2.1 可信度

**可信度：**
- 根据经验对一个事物或现象为真的相信程度
- 带有较大的主观性和经验性

**C-F模型：**
- 基于可信度表示的不确定性推理的基本方法

#### 4.2.2 知识不确定性的表示

**产生式规则表示：**
```
IF E THEN H (CF(H, E))
```
- CF(H, E)：可信度因子，反映前提条件与结论的联系强度
- CF(H, E)的取值范围：[-1, 1]

#### 4.2.3 证据不确定性的表示

**证据E的可信度取值范围：** [-1, 1]
- CF(E) = 1：肯定为真
- CF(E) = -1：肯定为假
- 0 < CF(E) < 1：以某种程度为真
- -1 < CF(E) < 0：以某种程度为假
- CF(E) = 0：未获得任何相关的观察

#### 4.2.4 组合证据不确定性的算法

**组合证据：**
- 多个单一证据的合取：CF(E) = min{CF(E1), CF(E2), …, CF(En)}
- 多个单一证据的析取：CF(E) = max{CF(E1), CF(E2), …, CF(En)}

#### 4.2.5 不确定性的传递算法

**结论H的可信度：**
```
CF(H) = CF(H, E) × max{0, CF(E)}
```

#### 4.2.6 结论不确定性的合成算法

**分别对每一条知识求出CF(H)：**
```
CF1(H) = CF(H, E1) × max{0, CF(E1)}
CF2(H) = CF(H, E2) × max{0, CF(E2)}
```

**综合可信度：**
```
CF12(H) = 
  if CF1(H) ≥ 0, CF2(H) ≥ 0:
    CF1(H) + CF2(H) - CF1(H) × CF2(H)
  if CF1(H) < 0, CF2(H) < 0:
    CF1(H) + CF2(H) + CF1(H) × CF2(H)
  if CF1(H) × CF2(H) < 0:
    CF1(H) + CF2(H)
  if CF1(H) × CF2(H) > 0:
    (CF1(H) + CF2(H)) / (1 - min{|CF1(H)|, |CF2(H)|})
```

### 4.3 证据理论

#### 4.3.1 概率分配函数

**样本空间D：**
- 变量x所有可能取值的集合，D中的元素是互斥的

**概率分配函数（basic probability assignment function）：**
- 设函数M：2^D → [0, 1]
- 满足：
  1. M(Φ) = 0
  2. ΣA⊆D M(A) = 1

#### 4.3.2 信任函数

**命题的信任函数（belief function）：**
```
Bel(A) = ΣB⊆A M(B)
```
- 对命题A为真的总的信任程度

#### 4.3.3 似然函数

**似然函数（plausibility function）：**
```
Pl(A) = 1 - Bel(¬A)
```
- 不可以驳斥函数或上限函数

#### 4.3.4 概率分配函数的正交和（证据的组合）

**定义：**
- 设M1和M2是两个概率分配函数
- 则其正交和M = M1 ⊕ M2：
  ```
  M(Φ) = 0
  M(A) = K × ΣX∩Y=A M1(X) × M2(Y)
  ```
  其中：
  ```
  K = 1 / (1 - ΣX∩Y=Φ M1(X) × M2(Y))
  ```

### 4.4 模糊推理方法

#### 4.4.1 模糊集合

**论域：** 所讨论的全体对象

**元素：** 论域中的每个对象

**集合：** 论域中具有某种相同属性的确定的、可以彼此区别的元素的全体

**模糊集合：**
- 给集合中每一个元素赋予一个介于0和1之间的实数，描述其属于一个集合的强度
- 该实数称为元素属于一个集合的隶属度

**隶属函数：**
- μ_A(x)：元素x属于模糊集合A的隶属度

**示例：**
```
μ_成年人(x) = 
  0, x < 18
  (x - 18) / 2, 18 ≤ x ≤ 20
  1, x > 20
```

#### 4.4.2 模糊集合的表示方法

**1. Zadeh表示法：**
- 离散且元素数目有限：A = μA(x1)/x1 + μA(x2)/x2 + … + μA(xn)/xn
- 连续的或元素数目无限：A = ∫U μA(x)/x

**2. 序偶表示法：**
A = {(μA(x1), x1), (μA(x2), x2), …, (μA(xn), xn)}

**3. 向量表示法：**
A = [μA(x1), μA(x2), …, μA(xn)]

#### 4.4.3 模糊集合的运算

**1. 交运算：**
```
μA∩B(x) = min{μA(x), μB(x)}
```

**2. 并运算：**
```
μA∪B(x) = max{μA(x), μB(x)}
```

**3. 补运算：**
```
μĀ(x) = 1 - μA(x)
```

#### 4.4.4 模糊关系与模糊关系的合成

**模糊关系：**
- 从X到Y的一个模糊关系R，用模糊矩阵表示

**模糊关系的合成：**
- 设R是X到Y的模糊关系，S是Y到Z的模糊关系
- 则R和S的合成T = R ∘ S是X到Z的模糊关系

#### 4.4.5 模糊推理

**模糊规则：**
- 从条件论域到结论论域的模糊关系矩阵R
- 通过条件模糊向量与模糊关系R的合成进行模糊推理

**IF A THEN B类型的模糊规则的推理：**
```
B' = A' ∘ R
```

#### 4.4.6 模糊决策

**1. 最大隶属度法：**
- 选取隶属度最大的元素作为决策结果

**2. 加权平均判决法：**
```
U = Σμ(ui) × ui / Σμ(ui)
```

**3. 中位数法：**
- 选取使隶属度累积和达到0.5的元素

## 第5章 搜索求解策略

### 5.1 搜索的概念

**问题求解的基本方法：**
- 搜索法
- 归约法
- 归结法
- 推理法
- 产生式

#### 5.1.1 搜索的基本问题

1. 是否一定能找到一个解
2. 找到的解是否是最佳解
3. 时间与空间复杂性如何
4. 是否终止运行或是否会陷入一个死循环

#### 5.1.2 搜索策略

**1. 搜索方向：**
- 数据驱动：从初始状态出发的正向搜索
- 目的驱动：从目的状态出发的逆向搜索
- 双向搜索：正向搜索与逆向搜索同时进行

**2. 盲目搜索与启发式搜索：**
- 盲目搜索：在不具有对特定问题的任何有关信息的条件下，按固定的步骤进行的搜索
- 启发式搜索：考虑特定问题领域可应用的知识，动态地确定调用操作算子的步骤

### 5.2 状态空间的搜索策略

#### 5.2.1 状态空间表示法

**状态：**
- 表示系统状态、事实等叙述型知识的一组变量或数组

**操作：**
- 表示引起状态变化的过程型知识的一组关系或函数

**状态空间：**
- 一个四元组：(S, O, S0, G)
  - S：状态集合
  - O：操作算子的集合
  - S0：包含问题的初始状态
  - G：若干具体状态或满足某些性质的路径信息描述

**求解路径：**
- 从S0到G的有限操作算子序列

### 5.3 盲目的图搜索策略

#### 5.3.1 回溯策略

**带回溯策略的搜索：**
- 从初始状态出发，不停地、试探性地寻找路径，直到它到达目的或"不可解结点"
- 若遇到不可解结点就回溯到路径中最近的父结点上

#### 5.3.2 宽度优先搜索策略

**宽度优先搜索（breadth-first search）：**
- 以接近起始节点的程度（深度）为依据，进行逐层扩展的节点搜索方法
- 特点：
  1. 每次选择深度最浅的节点首先扩展，搜索是逐层进行的
  2. 一种高价搜索，但若有解存在，则必能找到它

**OPEN表：** 已经生成出来但其子状态未被搜索的状态（先进先出）
**CLOSED表：** 记录了已被生成扩展过的状态

#### 5.3.3 深度优先搜索策略

**深度优先搜索（Depth-first Search）：**
- 首先扩展最新产生的节点，深度相等的节点按其生成顺序依次进行扩展
- 特点：
  - 扩展最深的节点
  - 为保证找到解，应选择合适的深度限制值

### 5.4 启发式图搜索策略

#### 5.4.1 启发式策略

**启发式信息：**
- 用来简化搜索过程有关具体问题领域的特性的信息

**启发式图搜索策略的特点：**
- 重排OPEN表，选择最有希望的节点加以扩展

#### 5.4.2 启发信息和估价函数

**启发信息：**
- 在具体求解中能够利用与该问题有关的信息来简化搜索过程

**估价函数（evaluation function）：**
- 估算节点"希望"程度的量度
- 一般形式：f(n) = g(n) + h(n)
  - g(n)：从初始节点S0到节点n的实际代价
  - h(n)：从节点n到目标节点Sg的最优路径的估计代价（启发函数）

#### 5.4.3 A搜索算法

**A搜索算法：**
- 使用了估价函数f的最佳优先搜索
- OPEN表：保留所有已生成而未扩展的状态
- CLOSED表：记录已扩展过的状态

#### 5.4.4 A*搜索算法及其特性分析

**A*搜索算法：**
- 当A搜索算法的启发函数h(n)小于等于h*(n)时，则被称为A*搜索算法

**A*搜索算法的特性：**
1. **可采纳性**：A*搜索算法是可采纳的，一定能搜索到最优解
2. **单调性**：对启发函数h(n)加上单调性的限制，可以减少比较代价和调整路径的工作量
3. **信息性**：h(n)越大，A*算法搜索的信息性越多，所搜索的状态越少

### 7.2 专家系统的概念

#### 7.2.1 专家系统的定义

- 专家系统是一种智能的计算机程序，它运用知识和推理来解决只有专家才能解决的复杂问题

**专家系统：**

3. **具有启发性**
4. **具有灵活性**
5. **具有透明性**

## 第8章 人工神经网络及其应用

### 8.1 神经元与神经网络

#### 8.1.1 生物神经元的结构

**人脑构造：**
- 由一千多亿（10^11－10^14亿）个神经细胞交织在一起的网状结构
- 大脑皮层约140亿个神经元，小脑皮层约1000亿个神经元

**生物神经元结构：**
- 树突、细胞体、轴突、突触

#### 8.1.2 神经元数学模型

**人工神经元模型（M-P模型）：**
```
y_i = f(Σj w_ij × x_j - θ_i)
```
- x_j：输入信号
- w_ij：权重
- θ_i：阈值
- f：激励函数

**激励函数的类型：**
1. 硬极限函数（阶跃函数）
2. 对数-S形函数（S型函数）
3. 双曲正切S形函数
4. ReLU函数

#### 8.1.3 神经网络结构与工作方式

**决定人工神经网络性能的三大要素：**
1. 神经元的特性
2. 神经元之间相互连接的形式——拓扑结构
3. 为适应环境而改善性能的学习规则

**神经网络的结构：**
1. 前馈型（前向型）
2. 反馈型（Hopfield神经网络）

**神经网络的工作方式：**
1. 同步（并行）方式
2. 异步（串行）方式

#### 8.1.4 神经网络的学习

**Hebb学习规则：**
- 当某一突触两端的神经元同时处于兴奋状态，那么该连接的权值应该增强

### 8.2 BP神经网络及其学习算法

#### 8.2.1 BP神经网络的结构

**BP网络结构：**
- 多层前向网络（输入层、隐层、输出层）
- 层与层的连接是单向的，信息的传播是双向的

#### 8.2.2 BP学习算法

**BP定理：**
- 给定任意ε > 0，对于任意的连续函数，存在一个三层前向神经网络，它可以在任意平方误差精度内逼近连续函数

**BP学习算法：**
1. 正向传播：输入信息由输入层传至隐层，最终在输出层输出
2. 反向传播：修改各层神经元的权值，使误差信号最小

**连接权值修正公式：**
- 输出层连接权调整公式：
  ```
  w_ij = w_ij + η × (d_i - y_i) × y_i × (1 - y_i) × x_j
  ```
- 隐层连接权调整公式：
  ```
  w_ij = w_ij + η × [Σl (d_l - y_l) × w_li] × y_i × (1 - y_i) × x_j
  ```
  其中η为学习率

#### 8.2.3 BP算法的实现

**BP算法的设计：**
1. 隐层数及隐层神经元数的确定
2. 初始权值的设置
3. 训练数据预处理
4. 后处理过程

**BP算法的计算机实现流程：**
1. 初始化：对所有连接权和阈值赋以随机任意小值
2. 从N组输入输出样本中取一组样本
3. 正向传播：计算各层节点的输出
4. 计算网络的实际输出与期望输出的误差
5. 反向传播：从输出层方向计算到第一个隐层
6. 让t+1→t，取出另一组样本重复（2）－（5），直到N组输入输出样本的误差达到要求

**BP算法的特点分析：**
- 优点：很好的逼近特性、较强的泛化能力、较好的容错性
- 缺点：收敛速度慢、局部极值、难以确定隐层和隐层结点的数目

### 8.3 BP神经网络在模式识别中的应用

**模式识别：**
- 研究用计算机模拟生物、人的感知，对模式信息如图像、文字、语音等，进行识别和分类

**神经网络模式识别方法的特点：**
- 较强的容错能力
- 自适应学习能力
- 并行信息处理能力

### 8.4 Hopfield神经网络及其改进

#### 8.4.1 离散型Hopfield神经网络

**离散Hopfield神经网络模型：**
```
x_i(k+1) = f(Σj w_ij × x_j(k) - θ_i)
```
- w_ij：连接权
- θ_i：阈值
- f：硬极限函数

**网络的稳定性：**
- 并行稳定性：W为非负定对称阵
- 串行稳定性：W为对称阵

#### 8.4.2 连续型Hopfield神经网络及其VLSI实现

**连续Hopfield神经网络模型：**
```
C_i × du_i/dt = Σj w_ij × v_j - u_i/R_i + I_i
v_i = f(u_i)
```

**网络的稳定性：**
- 计算能量函数：
  ```
  E = -1/2 × Σi Σj w_ij × v_i × v_j + Σi I_i × v_i + Σi (1/R_i) × ∫0^v_i f^-1(v) dv
  ```
- 若f(·)为单调递增的连续函数，C_i > 0, w_ij = w_ji，则dE/dt ≤ 0

#### 8.4.3 随机神经网络

**Boltzmann机：**
- 1985年，加拿大多伦多大学教授Hinton等人提出
- 按Boltzmann概率分布动作的神经网络

### 8.5 Hopfield神经网络的应用

#### 8.5.1 Hopfield神经网络在联想记忆中的应用

**联想记忆功能：**
- 网络能够通过联想来输出和输入模式最为相似的样本模式

#### 8.5.2 Hopfield神经网络优化方法

**用神经网络方法求解优化问题的一般步骤：**
1. 将优化问题的每一个可行解用换位矩阵表示
2. 将换位矩阵与由n个神经元构成的神经网络相对应
3. 构造能量函数，使其最小值对应于优化问题的最优解
4. 用罚函数法构造目标函数，与Hopfield神经网络的计算能量函数表达式相等
5. 给定网络初始状态和网络参数等，使网络按动态方程运行

### 8.6 卷积神经网络与深度学习

#### 8.6.1 卷积神经网络的结构

**卷积神经网络（CNN）：**
- 一个多层的神经网络，每层由多个二维平面组成
- C层为特征提取层（卷积层）
- S层是特征映射层（下采样层）
- CNN中的每一个C层都紧跟着一个S层

#### 8.6.2 卷积神经网络的卷积运算

**特征提取层（卷积层）——C层：**
- 大部分的特征提取都依赖于卷积运算
- 利用卷积算子对图像进行滤波，可以得到显著的边缘特征

#### 8.6.3 卷积神经网络中的关键技术

1. **局部链接**
2. **权值共享**
3. **多卷积核**
4. **池化**

#### 8.6.4 卷积神经网络的应用

**LeNet-5：**
- 一种典型的用来识别数字的卷积网络
- 美国大多数银行当年用它识别支票上面的手写数字，达到了商用步

#### 8.6.5 胶囊网络

**胶囊网络的特点：**
- 胶囊是一个包含多个神经元的载体
- 胶囊网络的核心思想：胶囊里封装的检测特征的相关信息是以向量的形式存在的

### 8.7 生成对抗网络及其应用

#### 8.7.1 生成对抗网络的基本原理

**生成对抗网络（GAN）：**
- 使用对抗训练机制对两个神经网络进行训练
- 深度学习模型分为判别式模型和生成式模型
- Goodfellow等人于2014年提出

#### 8.7.2 生成对抗网络的结构与训练

**GAN的两个相互交替的训练阶段：**
1. 固定生成网络，训练判别网络
2. 固定判别网络，训练生成网络

#### 8.7.3 生成对抗网络的应用

1. 深度学习在博弈中的应用
2. 深度学习在医学影像识别中的应用
3. 生成对抗网络在图像处理中的应用
4. 生成对抗网络在语言处理中的应用

### 9.1 智能体的概念与结构

#### 9.1.1 智能体的概念

**Agent：**
- 可以看做是一个程序或者一个实体，它嵌入在环境中，通过传感器感知环境，通过效应器自治地作用于环境并满足设计要求

```
环境 ←→ Agent ←→ 传感器
        ↓
      执行器
```

#### 9.1.2 智能体的特性

1. **自主性**：Agent具有独立的局部于自身的知识和知识处理方法
2. **反应性**：Agent能够感知、影响环境
3. **社会性**：Agent具有和外部环境中其它Agent相互协作的能力
4. **进化性**：Agent应该能够在交互过程中逐步适应环境

#### 9.1.3 智能体的结构

**Agent = 体系结构 + 程序**

**单个Agent的结构按属性可以分为：**

**慎思式Agent：**
