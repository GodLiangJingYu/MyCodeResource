# 装载问题 - 分支限界法实现

## 问题描述
某港口有两艘货轮，第一艘货轮的载重量为C1，第二艘货轮的载重量为C2。现有n个集装箱需要装载，第i个集装箱的重量为wi。要求设计一个装载方案，将所有集装箱装上这两艘货轮。

## 文件说明
- `loading_problem.cpp`: 主要代码文件，包含完整的框架，需要你实现核心算法
- `test_cases.txt`: 测试用例文件，包含多个测试场景
- `README.md`: 说明文档

## 编译运行
```bash
g++ -o loading_problem loading_problem.cpp
./loading_problem
```

## 输入格式
```
第一行：三个整数 n, C1, C2 (1 ≤ n ≤ 20, 1 ≤ C1, C2 ≤ 1000)
第二行：n个整数，表示n个集装箱的重量 w1, w2, ..., wn (1 ≤ wi ≤ 500)
```

## 输出格式
```
第一行：如果存在装载方案，输出"Yes"，否则输出"No"
第二行：如果存在方案，输出第一艘货轮的装载重量（最大可能值）
第三行：输出具体的装载方案（第一艘货轮装载的集装箱编号，用空格分隔）
```

## 需要实现的算法
在 `LoadingProblem::solveLoadingProblem()` 函数中实现FIFO队列式分支限界算法。

### 算法提示
1. 使用队列存储活结点
2. 使用-1作为分层标记
3. 对每个结点进行分支：
   - 左子树：装载当前集装箱
   - 右子树：不装载当前集装箱
4. 使用上界函数进行剪枝
5. 更新最优解和最优路径

### 关键数据结构
```cpp
struct Node {
    int cw;              // 当前装载重量
    int level;           // 当前层数
    vector<int> path;    // 当前路径（装载的集装箱编号）
    int ub;              // 上界（用于剪枝）
};
```
